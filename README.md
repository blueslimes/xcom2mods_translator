# XCOM 2 模組正體中文翻譯附翻譯器

*Traditional Chinese translations for XCOM 2 mods, with a translator included.*

收錄多款 XCOM 2 模組的正體中文翻譯，並提供翻譯器協助翻譯。

## 資料夾內容

- **模組翻譯**：依模組分類的翻譯檔。請保留原有資料夾結構，不要將不同模組的檔案混在一起。
- **翻譯器**：用於協助處理翻譯的工具。使用方式、必要環境及支援格式請以工具附帶的說明為準。

## 使用翻譯

1. 先透過 Steam 工作坊訂閱並安裝翻譯所對應的模組。
2. 找到該模組的工作坊目錄，通常在 `Steam\steamapps\workshop\content\268500\<模組ID>\`。可在 Steam 工作坊頁面網址中找到模組 ID。
3. 將翻譯檔依照其目錄結構，放入模組中對應的位置。XCOM 2 模組的語言資源通常放在 `<模組ID>\Localization`。
4. 啟動遊戲，並確認遊戲語言設定為繁體中文。若翻譯沒有顯示，請檢查模組 ID、檔案路徑、遊戲語言，以及是否有其他翻譯或模組覆蓋相同文字。

註：『正體翻譯』及『未校稿』資料夾內都是已翻譯的文件，使用未校稿內的文件可能會影響遊戲體驗。

## 使用翻譯器

翻譯器 `ini_translator.ipynb` 預設使用 Google 翻譯免費 API。機器翻譯品質有限，結果可能不準確；免費服務也可能隨時變更、受到限制或停止，造成翻譯失敗。請務必校對翻譯結果。

請先閱讀翻譯器隨附的說明，再確認輸入檔格式、語言設定及輸出位置。建議先複製一份檔案進行測試，檢查輸出內容與目錄結構無誤後，再將結果放入對應模組。不要在不了解工具作用時，對整個工作坊目錄執行批次處理。
